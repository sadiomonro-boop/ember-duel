Ember Duel is an original turn-based card duel, played in the browser with mouse or keyboard. You and a rival each have 30 life, a 5-card hand and energy that grows every turn. Play cards from an original 24-card deck across four suits — Flame, Leaf, Wave and Star, each told apart by colour and shape — to strike, guard or draw. The rival plays with readable logic: it takes lethal when it sees it, guards when hurt, and spends the rest on its biggest attacks. Win by bringing the rival to 0 life; lose if yours hits 0.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click to play. Keys 1–5 play a card, Enter ends your turn, R restarts, Esc returns to the title screen.

Screenshot states (seeded, reproducible): `?shot=title`, `?shot=play`, `?shot=win`, `?shot=loss`.
